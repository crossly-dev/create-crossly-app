# __APP_NAME__

A [Crossly](https://crossly.net) webhook receiver on [Hono](https://hono.dev) and Cloudflare Workers. It verifies the
`Crossly-Signature` header over the raw body with `verifyWebhook` from
[`@crossly/sdk`](https://github.com/crossly-dev/crossly-sdk) (Web Crypto, so it runs on Workers unchanged), answers at
once, and runs your typed handler with `waitUntil`.

## Run it

```sh
__PM_INSTALL__
cp .env.example .dev.vars   # paste CROSSLY_WEBHOOK_SECRET
__PM_DEV__                  # wrangler dev: http://localhost:8787/webhooks/crossly
```

## Deploy

```sh
__PM_EXEC__ wrangler login
__PM_EXEC__ wrangler secret put CROSSLY_WEBHOOK_SECRET
__PM_DEPLOY__
```

Then in Crossly open **Settings → API & webhooks → Webhooks → Add endpoint**, paste
`https://__WORKER_NAME__.<your-subdomain>.workers.dev/webhooks/crossly`, and press **Send test**:
`wrangler tail` shows `[test] Hello from Crossly!`. The signing secret is shown once, when you add the endpoint.

## How it works

- **Raw body.** The route reads `c.req.text()` before anything parses it. Never call `c.req.json()` first.
- **Secrets on `c.env`.** Workers have no `process.env` at module scope; the secret is a binding, read per request.
  A missing binding answers `500` so Crossly keeps retrying until you set it.
- **Status codes.** `400` for a forged, tampered, stale (over 5 minutes) or malformed delivery.
- **Answer first, then work.** Crossly waits at most 10 seconds. `handleEvent` runs in `waitUntil` after the `200`. A
  failure there is not retried by Crossly, so for work that must not be lost, push the event to a
  [Queue](https://developers.cloudflare.com/queues/) from the handler and process it in a consumer.
- **At-least-once.** Retries carry the same `event.id`. Dedupe with KV or D1 if a handler must not run twice.
- **Typed events.** [`src/events.ts`](src/events.ts) has all 69 event names in the
  [catalog](https://crossly.net/docs/api-webhooks) and the documented payloads.

Prefer one line? [`@crossly/hono`](https://github.com/crossly-dev/crossly-webhooks-js/tree/main/packages/hono) is this
route as middleware: `app.post('/webhooks/crossly', crosslyWebhook({ secret: (c) => c.env.CROSSLY_WEBHOOK_SECRET, onEvent }))`.
