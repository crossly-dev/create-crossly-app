# __APP_NAME__

A [Crossly](https://crossly.net) webhook receiver on Express 5. It verifies the `Crossly-Signature` header over the
raw request body with `verifyWebhook` from [`@crossly/sdk`](https://github.com/crossly-dev/crossly-sdk), drops
duplicate deliveries, and hands each event to a typed `switch` in [`src/handlers.ts`](src/handlers.ts).

## Run it

```sh
__PM_INSTALL__
cp .env.example .env        # paste CROSSLY_WEBHOOK_SECRET
__PM_DEV__                  # http://localhost:3000/webhooks/crossly
```

1. In Crossly, open **Settings → API & webhooks → Webhooks → Add endpoint**. Paste your public URL ending in
   `/webhooks/crossly`, pick events (none = all of them), and copy the signing secret into `.env`. It is shown once.
2. While you build, forward live events to this machine without a tunnel, using the
   [Crossly CLI](https://github.com/crossly-dev/crossly-cli): `__PM_DLX__ @crossly/cli login`, then
   `__PM_DLX__ @crossly/cli dev --forward http://localhost:3000/webhooks/crossly`.
3. Press **Send test** on the endpoint. You should see `[test] Hello from Crossly!`. Through the API,
   `POST /v1/webhooks/{id}/test` with `{ "event": "order.created" }` sends a sample of any event in its real shape.

## How it works

- **Raw body.** The webhook route is registered before `express.json()` and uses `express.raw()`, so the handler
  verifies the exact bytes Crossly signed. Verifying `JSON.stringify(req.body)` instead fails on genuine events; that
  is the most common webhook bug there is.
- **Status codes.** `400` for a forged, tampered, stale (older than 5 minutes) or malformed delivery; `500` when your
  handler throws or the secret is missing, so Crossly retries (5 attempts, exponential backoff from 5 s). Answer
  within 10 seconds: put slow work on a queue.
- **At-least-once.** A retry carries the same `event.id`, so the app remembers ids it has handled. The in-memory set
  resets on restart; in production, record event ids in your database with a unique index.
- **Typed events.** [`src/events.ts`](src/events.ts) lists all 69 event names in the
  [catalog](https://crossly.net/docs/api-webhooks) with the documented payloads. Keep the `default:` branch: Crossly
  can add event types at any time.

## Deploy

Any Node 20.12+ host works: `__PM_BUILD__ && __PM_START__`, with `CROSSLY_WEBHOOK_SECRET` set in the environment and
HTTPS in front (Crossly only delivers to HTTPS URLs in production).

Prefer one line? [`@crossly/express`](https://github.com/crossly-dev/crossly-webhooks-js/tree/main/packages/express)
wraps this route as `app.post('/webhooks/crossly', crosslyWebhook({ secret, onEvent }))`.
